Rescheduling:

If you need to reschedule, contact us as soon as possible with a few alternative times. We will do our best to find a new slot that works for both parties.

Tutor cancellations:

In the rare event that we need to cancel a lesson (due to illness or emergency), you will be notified as soon as possible and offered:

4. Lessons

How lessons work:

  • Lessons are delivered online via Microsoft Teams
  • We use OneNote for shared notes, which you can access after the session
  • If needed, we use Excalidraw for interactive whiteboard work
  • You will need a stable internet connection and a device that can run Microsoft Teams

Lesson length:

  • GCSE: 60 minutes (recommended)
  • A-Level Maths: 60 minutes
  • A-Level Physics: 60 or 90 minutes (depending on your needs)
  • University: We'll discuss the best length in your free intro call

Homework and support:

  • Optional homework can be provided after each lesson
  • You can email questions between sessions, and we will reply when possible
  • If a topic needs more time, we can cover it in the next session
